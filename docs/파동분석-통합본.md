## 0. 왜 닐리를 기반으로 삼는가

고전 엘리어트는 규칙이 3개뿐이라 **후보를 좁히지 못한다.** "이 카운트가 규칙을
어겼는가"만 물을 수 있는 검증기다.

닐리는 다르다:

> 파동을 세기 전에 **각 조각의 내부 구조부터 판정한다.**
> 그 판정은 주관이 아니라 **이웃 조각과의 되돌림 비율**로 기계적으로 나온다.

**검증기보다 생성기가 값지다.** 그래서 닐리가 먼저 돌고 고전이 뒤에서 거른다.

| | 고전 엘리어트 | 닐리 NEoWave |
|---|---|---|
| 분석 단위 | 파동(1,2,3,4,5) | **모노파동** (방향 전환 사이 한 조각) |
| 구조 판정 | 눈으로 본다 | **되돌림 비율표로 기계 판정** |
| 규칙 수 | 3개 | 법칙 7 × 조건 4~6 × 범주 3 |
| 시간 | 거의 안 씀 | 1급 변수 |
| 결과 | 하나의 카운트 | **신뢰도 순위가 붙은 복수 후보** |

# 1장 · 닐리 NEoWave — 기반 레이어

## 1.1 모노파동

**방향 전환과 방향 전환 사이의 단일 방향 움직임 한 조각.**

`pivot.js`가 뽑는 **인접 두 피벗 사이 구간이 곧 모노파동**이다. 별도 자료구조 불필요.

```
피벗:      P0    P1    P2    P3    P4
모노파동:    └─m1─┘└─m2─┘└─m3─┘└─m4─┘
```

분석 대상을 **m1**, 그 앞을 **m0**, 뒤를 **m2**, 그 뒤를 **m3**라 한다.
m1은 반드시 모노파동 하나여야 하지만, m0·m2는 여러 조각이 뭉친 것이어도 된다.

> 닐리는 **"한 화면에 모노파동 20개를 넘기지 마라"** 고 못박는다.
> → `PIVOT_K`(ATR 배수)로 **시간축당 피벗 15~25개**를 유지한다.

## 1.2 예비적 분석 3법칙

되돌림 법칙 적용 **전에** 통과시켜야 하는 관문.

**① 비례의 법칙** — 시간축/가격축 비율 왜곡 방지 ★구현됨 (`scale.js`)
→ *구현*: 숫자 계산이라 "보기 왜곡"은 없지만 같은 문제가 다른 얼굴로 남는다 —
**산술 척도로 잰 되돌림 비율은 등락폭이 큰 구간에서 어긋난다.**

| 100 → 200 → 135 | 상승 | 하락 | 되돌림 | 법칙 |
|---|---|---|---|---|
| 산술 | 100 | 65 | **65.0%** | 4 (61.8~100) |
| 로그 | .693 | .393 | **56.7%** | 2 (38.2~61.8) |

같은 세 점인데 법칙 번호가 갈린다. 그래서 `scale.js` 는
1. 구간 최고/최저가 배수가 **2배 이상**이면 로그를 주 척도로 잡고(`autoUseLog`),
2. 주 척도로 법칙 번호를 정하되,
3. **다른 척도에서만 나오는 법칙도 후보로 남긴다** (중립성의 법칙과 같은 처리).

조건 문자(`m0/m1`)도 같은 척도로 잰다. 안 그러면 앞뒤가 어긋난다.
갈리지 않으면 아무것도 출력하지 않는다 — 조용한 것이 정상이다.

**② 중립성의 법칙** — 겹치며 옆으로 기어 전환점이 모호한 구간
→ *구현*: 되돌림 비율이 경계(38.2 / 61.8 / 100 / 161.8 / 261.8%)에
**±3%p 이내면 "중립"으로 보고 양쪽 법칙을 모두 후보로 남긴다.**

**③ 관측의 법칙** — m0·m2의 끝점 확정
핵심은 **"m1의 고점 또는 저점을 이탈해야 그 모노파동이 끝난 것"**.
한 조각으로 못 넘으면 여러 조각을 합쳐 센다.

## 1.3 되돌림 법칙 — 이 체계의 심장

**`m2/m1`이 법칙 번호를, `m0/m1`이 조건(a~f)을 정한다.**
법칙 4만 `m3/m2`로 범주(i~iii)가 한 단계 더 갈린다.

### 법칙 번호 — `m2 / m1`

| 법칙 | 범위 | 해석 |
|---|---|---|
| **1** | < 38.2% | 얕은 되돌림 — m1이 충격파일 가능성 |
| **2** | 38.2 ~ 61.8% | 정상 되돌림 |
| **3** | **정확히 61.8%** | **충격/조정 경계 — 판정 최난** |
| **4** | 61.8 ~ 100% | 깊은 되돌림 (m3/m2로 재분기) |
| **5** | 100 ~ 161.8% | 완전 되돌림 — m1이 조정파일 가능성 |
| **6** | 161.8 ~ 261.8% | 초과 되돌림 |
| **7** | > 261.8% | 극단 초과 |

### 조건 — `m0 / m1`

| 법칙 | 조건 경계 |
|---|---|
| 1 | a: <61.8 / b: 61.8~100 / c: 100~161.8 / d: >161.8 |
| 2 | a: <38.2 / b: 38.2~61.8 / c: 61.8~100 / d: 100~161.8 / e: >161.8 |
| 3 | a: <38.2 / b: 38.2~61.8 / c: 61.8~100 / d: 100~161.8 / e: 161.8~261.8 / f: >261.8 |
| 4 | a: <38.2 / b: 38.2~100 / c: 100~161.8 / d: 161.8~261.8 / e: >261.8 |
| 5 | a: <100 / b: 100~161.8 / c: >161.8 |
| 6 | a: <100 / b: 100~161.8 / c: 161.8~261.8 / d: >261.8 |
| 7 | a: <100 / b: 100~161.8 / c: 161.8~261.8 / d: >261.8 |

> 6·7은 한때 스캔 손상으로 5번을 준용한 추정치였다. **원서 p.118 및 p.159~164에서
> 확인해 확정했다** — 3구간이 아니라 4구간이다. `estimated` 플래그는 제거됐다.

### 법칙 4의 범주 — `m3 / m2`

| 범주 | 범위 |
|---|---|
| i | 100 ~ 161.8% |
| ii | 161.8 ~ 261.8% |
| iii | > 261.8% |

## 1.4 구조기호

| 기호 | 뜻 |
|---|---|
| `:5` / `:3` | 5파(충격) / 3파(조정) 구조 |
| `:F3` | **F**irst 3 — 패턴을 여는 조정파 |
| `:c3` | **c**enter 3 — 패턴 중간 조정파 |
| `:L5` / `:L3` | **L**ast — 패턴을 닫는 파동 |
| `:s5` / `:sL3` | **s**econd — 두 번째 위치 |
| `x:c3` | X파동 — 복합 조정의 연결부 |

법칙별 가능 기호:

| 법칙 | 구조기호 |
|---|---|
| 1 | `:5` / `(:c3)` / `(x:c3)` / `[:sL3]` / `[:s5]` |
| 2 | `:5` / `(:sL3)` / `[:c3]` / `[:s5]` |
| 3 | `:F3` / `:c3` / `:s5` / `:5` / `(:sL3)` / `[:L5]` |
| 4 | `:F3` / `:c3` / `:s5` / `(:sL3)` / `(x:c3)` / `[:L5]` |
| 5 | `:F3` / `:c3` / `:5` / `:L5` / `(:L3)` |
| 6·7 | `:5` / `:s5` / `:F3` / `:L5` / `(:L3)` |

> 4·6·7의 기호집합도 원서 p.159~164에서 채워 넣었다. `partial` 플래그 역시 제거됐다.

### 포지션 지표에 따른 가장자리 제외 (3장)

`:c3` 는 패턴의 **시작점도 끝점도 될 수 없고**, `x:c3` 역시 연속 파동의 시작·끝에
올 수 없다. 그래서 첫 모노파동과 마지막 모노파동에서는 이 둘을 후보에서 뺀다
(`neowave.js`, 표시: `가장자리 필터`). 단, 이 필터로 후보가 0이 되면 원래 집합을
되살린다 — 후보를 없애는 것이 목적이 아니라 좁히는 것이 목적이다.

## 1.4-b 논리적 사전 구성법칙 (닐리 3장) ★구현 완료 — `preconstruction.js`

되돌림 법칙까지 오면 "법칙 N, 조건 x"는 나오지만 구조기호는 **여전히 3~6개 목록**이다.
그 중 어느 것인지를 가르는 절이 이것이다. 원문 형식:

```
법칙 1 {:5 / (:c3) / (x:c3) / [:sL3] / [:s5]}
  조건 'a' — m0가 m1의 61.8%보다 작은 경우
    "만약 m2가 형성되는 데 m1과 같거나 그보다 긴 시간이 걸렸거나 …
     m1의 끝에 :5를 기입하라."
```

**문단마다 첫 문장이 관문이다.** 원문도 그렇게 지시한다 — *"각각의 단락의 첫 번째
문장을 잘 따르는 것이 가장 중요하다. 만약 첫 번째 문장에서 기술된 조건이 실제 시장
움직임에 반영되지 않는다면 다음 단락으로 옮겨가야 한다."*(p.124)

### 오차 규약 (p.123) — 이 절 전체에 적용된다

| 표현 | 허용 오차 |
|---|---|
| "61.8%의 관계" | **58~66%** (상하 4%p) |
| "거의(almost)" · "가깝게(close to)" | 언급 비율의 **10% 이내** |
| 시간 비교 | **문자 그대로 정확히** |
| m1 되돌림 시간 비교 | m1 소요 시간에 **한 단위를 더한 뒤** 비교 |

### 수록 범위 — 32/32 조건

| 법칙 | 조건 | 상태 |
|---|---|---|
| 1 | a b c d | ✅ 전부 |
| 2 | a b c d e | ✅ 전부 |
| 3 | a b c d e f | ✅ 전부 — a·b·c는 m3/m1, d·e·f는 m3/m2 3구간으로 갈린다 |
| 4 | a b c d e | ✅ 전부 — 조건마다 m3/m2 범주(i/ii/iii)가 한 단계 더 갈린다 |
| 5 | a b c d | ✅ 전부 — **이 표를 채우며 원문(p.151~158)을 다시 읽다가 CONDITIONS[5]가 3구간(a~c)으로
  잘못 추정돼 있던 걸 발견해 같이 고쳤다.** 실제는 6·7과 같은 4구간(a~d)이다 |
| 6 | a b c d | ✅ 전부 |
| 7 | a b c d | ✅ 전부 |

**전량을 옮기지 않은 이유는 정직함 때문이다.** 이 절은 원서에서 36,000자가 넘고
문단이 수백 개인데, 스캔 OCR이 `m0`을 `mO`·`m07^`·`애`로 깨뜨린 곳이 많고, 한 조건 안에
같은 결론으로 좁히기까지 5~10개의 중첩된 if/then 문단이 이어지는 경우가 흔하다.
그래서 조건마다 **가장 먼저 나오고 가장 명확하게 검증 가능한 관문 1~3개만** 옮겼다
(법칙 1·2와 같은 밀도). 문단 안쪽 깊숙이 있는 부차적 조건, 그리고 "m2/m3가 3개
이상의 모노파동(폴리파동)으로 구성된 경우" 분기(법칙 5·6·7의 조건 a에 반복 등장)는
이 프로젝트가 모노파동 단위로만 피벗을 잡기 때문에 애초에 판별할 수 없어 뺐다 —
항상 "3개 이하" 쪽 분기로 본다. 엔진은 매 실행마다 수록 범위를 출력한다.

### 실제 효과

법칙 1·2는 사실상 모든 조건에서 `:5`가 확정된다. 특히

- **R1d** (m0 > m1의 161.8%) — 원문 *"이런 상황에서는 하나의 가능성만이 존재한다"*
- **R2e-2** (m3가 m1보다 짧고 완만) — 원문 *"선택 대상은 :5밖에 없다"*

이 둘은 `exclusive` 로 표시돼 **후보 목록 자체를 `:5` 하나로 줄인다.**
나머지는 확정 표시만 달고 목록은 남긴다 — 원문이 "다른 가능성도 읽어보라"고
덧붙인 경우가 대부분이기 때문이다.

### 괄호 = 신뢰도

| 표기 | 신뢰도 | 가중치 |
|---|---|---|
| `:5` 맨몸 | 유력 | 1.0 |
| `(:c3)` 소괄호 | 낮음 | 0.6 |
| `[:s5]` 대괄호 | 매우 낮음 | 0.3 |

## 1.5 방향성 / 비방향성

| | 조건 | 종료 조건 |
|---|---|---|
| **방향성** | 첫 모노파동이 61.8% **초과 되돌려지지 않음** | 중심 추세 방향 모노파동이 100% 되돌려질 때 |
| **비방향성** | 첫 모노파동이 61.8% **이상 되돌려짐**<br>(예외 1구간 제외 전 구간) | 가격이 구간 범위의 **161.8%를 벗어날 때** |

**비방향성 국면에서 방향 베팅을 설계하는 것이 손실의 주된 원인이다.**
→ 이 판정이 시간축 정렬(PRISM)의 1급 재료.

## 1.6 패턴 분리

`:L5` 또는 `:L3` 발견 지점 = **한 엘리어트 패턴의 끝.**
거기에 표시하고 좌우로 구조를 확정해 나간다.

# 2장 · 고전 엘리어트 — 검증 레이어

## 2.1 절대 규칙 3개

| 규칙 | 내용 | 검증식 (상승 충격파) |
|---|---|---|
| **R1** | 2파는 1파 시작점을 넘어 되돌리지 못한다 | `P2 > P0` |
| **R2** | 3파는 1·3·5 중 최단일 수 없다 | `¬(len3 < len1 ∧ len3 < len5)` |
| **R3** | 4파는 1파 가격 영역을 침범하지 못한다 | `P4 > P1` |

**R3 예외: 다이아고날 · 삼각형** (모든 자료가 일치)

## 2.2 임펄스 규칙

- 1파·5파는 임펄스 **또는 다이아고날**
- **3파는 항상 임펄스** (다이아고날 불가)
- 2파는 **삼각형 제외** 모든 조정 패턴 가능 (단, 삼각형으로 끝나는 WXY/WXYZ는 가능)
- 4파는 **모든 조정 패턴 가능**
- 3파는 반드시 1파를 넘어야 한다

## 2.3 임펄스 가이드라인 — 코드로 쓸 수 있는 것

**하드 체크 (위반 시 카운트 폐기 후보)**
- **4파가 3파의 50% 이상을 되돌리면 4파가 아니다**
- **2파가 1파의 0.786 이상을 되돌리면 2파가 아닐 수 있다** (조정 AB파 주의)

**확장 규칙**
- 1·3·5 중 하나가 확장, **3파 확장 확률이 가장 높다**
- 1파 확장 → 3~5파 길이는 1파의 0.618~0.786 / 2·4파 짧음(0.236~0.382) /
  2파는 1파의 하위 4파 수준에서 끝난다
- 3파 확장 → **1파와 5파의 크기·지속시간이 거의 같다** (아니면 0.618 관계) /
  4파는 3파의 0.236~0.382
- 5파 확장 → 1파와 3파 크기가 같으면 5파 확장 가능 / 1~3파 길이의 1.618로 끝남 /
  후속 조정은 가파르고 짧으며 확장 5파의 하위 2파 끝단 부근에서 종료
- 사이클·슈퍼사이클급에서는 **3파와 5파가 동시에 확장**

**절단 (Truncation)**
- 5파가 3파를 넘지 못하고 끝나는 형태
- **3파가 예외적으로 길고 과도하게 늘어났을 때 발생**
- **절단 후에는 보통 큰 반전이 따른다**

**거래량**
- 보통 **3파에서 가장 큰 거래량**
- **5파 거래량이 3파만큼 높으면 확장 5파 예상**

**우선순위**
> **파동 카운트는 채널·피보나치 타깃보다 우선한다.**

## 2.4 교대 (Alternation)

**동인파동에서**
- 1파가 짧으면 → 3파 확장, 5파 다시 짧음
- 1파 확장 → 3·5파는 확장 안 됨
- 1·3파 모두 확장 안 됨 → **5파 확장 가능성 높음**
- 3파가 과도하게 길어짐 → **5파 절단 가능**

**조정파동에서**
- **2파 되돌림 비율이 4파보다 보통 더 크다** ← 방향성 있는 규칙
- 2파 = 단순 조정 (지그재그, 이중/삼중)
- 4파 = 복잡 조정 (삼각형, double/triple three, 플랫)
- 2파가 급각(짧은 시간) → **4파는 시간 끄는 횡보**
- 복잡도도 교대한다 (A 단순 → B 복잡 → C 더 복잡)

**균형 (Balance)**
- 2파는 **되돌림 깊고 시간 짧다** ↔ 4파는 **되돌림 얕고 시간 길다**
- 4파의 긴 시간이 2파의 깊은 되돌림과 균형을 이룬다
- **비율적으로 벗어나는 크기·지속시간이 나오면 카운팅을 의심하라**

## 2.5 채널링

- 5파는 **1-3 종점을 이은 채널선 연장 부근**에서 끝난다
- 4파는 **1-3에 평행한 선(2 저점 기준)** 에서 끝날 수 있다
- 3파가 비정상적으로 강하면 → 1파 고점에서 시작해 2-4 추세선에 평행한 선이 유리
- 3파가 확장·급경사면 1-2-4 채널을 뚫지만, **5파 종료 예측에는 여전히 유효**
- **임펄스는 채널이 2~3개 생겨 하나로 못 그린다 → 임펄스 진행 중엔 채널을 그리지 마라**
- **ABC 복합조정은 한 채널 안에 들어온다**
- 확장/러닝 플랫은 채널을 살짝 깰 수 있다

# 3장 · 조정 패턴

## 3.1 지그재그 (5-3-5)

**규칙**
- A파: 임펄스 또는 리딩 다이아고날 / C파: 임펄스 또는 엔딩 다이아고날
- **지그재그당 다이아고날은 하나만** (최소 하나의 임펄스가 있어야 함)
- B파는 모든 조정 패턴 가능

**비율**
- **A:C 비율 빈도 순서 — ① 1:1 ② 1:1.618 ③ 1:0.618**
- B파는 A파를 **0.382~0.786** 되돌린다
- B파 성격별: 삼각형이면 **0.1~0.4** / 지그재그면 **0.5~0.786** / 횡보면 **0.382~0.5**
- **B파가 삼각형이면 C파는 0.618 확장까지만**
- **절단**: A:C가 1:0.618을 넘지 못하면 절단 → 최소 81% 되돌림

**시간**
- **A:C가 1:1이면 소요 시간도 1:1**
- 피보나치 타임존: A 시작~끝 기준 **1.618 세로축이 B파의 끝**

**지그재그 vs 임펄스 구별법**
1. A-B가 1-2보다 훨씬 더 많이 겹친다
2. A파가 1파보다 시간·크기에서 빨리 끝난다
3. 지그재그는 완만한 채널, 1-2-3은 훨씬 가파르다

## 3.2 플랫 (3-3-5)

**규칙** — C파는 반드시 motive(임펄스 또는 다이아고날)
**B파는 A파를 90% 이상 되돌려야 한다**

| 종류 | 형태 | B파 (A 되돌림) | C파 (확장) |
|---|---|---|---|
| **레귤러** | a≈b≈c | 0.618 이상 | 1.0 / 1.382 / 1.618 |
| **확장(익스팬디드)** ★가장 흔함 | C가 A끝 초과 | **1.0 이상** (1.13/1.236/1.382/1.618) | 1.618 (2.236/2.618)<br>B가 1.13/1.236이면 역피보 -0.618/-1.618 |
| **러닝** ★매우 드묾 | B가 A시작 초과, C가 A끝 못 넘음 | 1.0 이상 | **1.0 넘지 않음** (0.786, 드물게 0.618) |

**하드 체크**
- **확장 플랫의 C파는 A파의 3배를 절대 넘을 수 없다**
- **확장 플랫 제외하고 ABC 조정이 1.786을 넘으면 ABC가 아니라 A파다**
- 확장 플랫 아니면 **1.618이 ABC 상승의 최대치**

> **플랫의 C파를 임펄스로 보고 진입하면 크게 당한다.** 둘은 비슷해 보이지만
> 플랫은 엄연한 조정파동이다.

## 3.3 B파 되돌림 → C파 확률 분포

**확률이 명시된 유일한 자료.** 목표가를 단일 값이 아니라 분포로 낼 수 있게 한다.

**B가 A를 0.618 되돌림:**

| C파 확장 | 확률 |
|---|---|
| 0.618 | 5% |
| **1.0** | **40%** |
| 1.382 | 5% |
| **1.618** | **40%** |
| 2.618 | 10% |

**B가 A를 0.7 이상 되돌림:**

| C파 확장 | 확률 |
|---|---|
| 1.0 | 20% |
| **1.382** | **40%** |
| **1.618** | **40%** |

**보조 규칙**
- B가 삼각수렴이면 → B점을 삼수의 끝(e)에 두고 0.618 / 0.786 확장
- **A에 대한 B 되돌림이 85~98%면 → B 확장 1.382에서 반등이 발생**
- **A에 대한 B 되돌림이 105~110% 초과면 → 확장 161.8%**
- 1:1 반등이면 **봉 개수도 비슷하게 나와야 한다**

## 3.4 삼각형 (3-3-3-3-3)

**위치 제한 — 여기서만 나온다**
① 임펄스의 4파 ② 지그재그·플랫의 B파 ③ Double Three의 Y파 ④ Triple Three의 Z파

**규칙**
- ABCDE 5개 파동 중 **4개 이상이 지그재그 ABC**
- 수렴형: C<A, D<B, E<C
- 확산형: B·C·D·E가 각각 이전 파동의 100% 이상 되돌림 ⚠(상한은 §9 확인사항)

**가이드라인**
- **러닝 수렴삼각형**(B가 A를 넘음) — 약 **60%** 로 꽤 자주 나온다
- E파는 추세선에 미치지 못하거나 살짝 넘긴다 (흔함)
- 수렴삼각형은 진행하며 **거래량·모멘텀 감소**
- 확산삼각형은 수렴형보다 훨씬 드물다
- E파가 삼각형이 되면 원래 삼각형이 9파(A~I)로 연장된다
- **E파 완성 후 5파는 시작부 추세 힘과 비슷한 추력이 생긴다**
- **선물시장에서 삼각형 이후 5파는 전체 추세에서 가장 긴 파동이 된다**
- 삼각수렴의 E파는 절단 가능

**비율**
- 수렴형: 대부분 파동이 이전 파동의 **0.618~0.786** 되돌림
- 러닝: B파는 A파를 **1.618 이하**로 되돌려야 함
- 확산형: C=A의, D=B의, E=C의 **1.618**
- **매수는 수렴 안이 아니라 삼각형 입구 크기의 1:1 하락 지점에서**

## 3.5 복합 조정 (WXY / WXYXZ)

- **X파는 항상 조정파동 이전의 추세 방향으로 뻗는다**
- Double Three = WXY (3개) / Triple Three = WXYXZ (5개), 트리플은 매우 드묾
- **지그재그와 삼각형은 W/Y/Z 중 최대 한 번씩만**
- **삼각형은 마지막 파동에서만** 형성
- X파는 모든 조정 패턴 가능
- 횡보 복합조정의 각 파동은 서로 **0.786~1.382** 되돌림
- **복합조정은 1.618만 안 넘으면 어떤 모양이든 성립**
- 오버라벨링 주의 — 원 이론대로 X파만 복합조정을 갖게 유지하는 것이 안전

### 범주 1 / 범주 2 — 이 판정 하나가 세력을 결정한다 ★구현됨

x파동이 W를 얼마나 되돌렸는가가 복합조정의 전부다. 이름(이중지그재그/이중조합)은
구성일 뿐이고, **다음 파동의 되돌림 한계를 정하는 것은 범주**다.

| x/W | 범주 | 패턴명 | 세력 | 다음 파동 되돌림 | 후속 충격파 |
|---|---|---|---|---|---|
| ≤ 61.8% | 1 (집약형) | 이중지그재그·이중플랫·이중조합 | **+2** | 80% 이하 | — |
| ≥ 161.8% | 2 (확산형) | 이중조정 | **−3** | 70% 이하 | 직전의 161.8% 이상 |
| ≥ 161.8% + 러닝 | 2 | 이중 강세조정 | **+3** | 70% 이하 | 161.8% 이상 (보통 261.8%) |
| 61.8~161.8% | **미확정** | — | +2 / −3 병기 | 80% / 70% 병기 | — |

러닝 판별은 "마지막 파동이 W의 끝을 넘지 못했는가" 하나다. 같은 범주 2 안에서
세력이 −3과 +3으로 정반대가 되므로 이 분기를 놓치면 결론이 뒤집힌다.

**구성 요건** (`corrective.js` `detectComplex`)
- W·Y·Z는 표준 조정패턴(지그재그·플랫)이어야 한다 — 모노파동 불가
- x파동은 모노파동 또는 표준 조정패턴 — 삼각형 불가 (9장 ⑨)
- 삼각형은 마지막 파동에서만, 그것도 수렴형만
- x파동은 W와 반대 방향, Y·Z는 W와 같은 방향
- W와 Y는 **유사성과 균형의 법칙**을 통과해야 한다 — 같은 등급이 아니면 복합조정이
  아니다. 가격이 아니라 시간으로만 통과한 경우는 경고를 붙여 내보낸다

# 4장 · 다이아고날

## 4.1 리딩 vs 엔딩

| | 리딩 | 엔딩 |
|---|---|---|
| 위치 | 추세 시작 | 추세 끝 |
| 등장 | 임펄스 1파 / 지그재그 A파 | 임펄스 5파 / 지그재그·플랫 C파 |
| 구조 | 5-3-5-3-5 또는 3-3-3-3-3 | 3-3-3-3-3 |
| 절단 | **불가** (5파가 3파를 반드시 넘어야) | **가능** |
| 특징 | 최소 2파나 4파 중 하나는 지그재그 | 5개 파동 모두 지그재그 |

**공통 규칙**
- 2파는 1파의 100% 이상 되돌릴 수 없다
- **4파는 1파와 겹친다** (R3 면제) ⚠(필수 여부는 §9 확인사항)
- **4파는 2파의 시작점을 넘지 않는다**
- 리딩 1파면 **3파 확장 가능성이 높다**

**수렴형 vs 확산형**

| | 수렴형 | 확산형 |
|---|---|---|
| 3파 vs 1파 | 3파가 짧다 | 3파가 길다 |
| 5파 vs 3파 | 5파가 짧다 | 5파가 길다 |
| 4파 vs 2파 | 4파가 짧다 | 4파가 길다 |
| 5파와 추세선 | **Throw-Over 또는 미달** ⚠§9 | 추세선에 못 미침 |

**가이드라인**
- 다이아고날의 2·4파는 임펄스의 2·4파보다 **훨씬 깊게 되돌린다**
- 엔딩 다이아고날은 끝으로 갈수록 **모멘텀 감소** → 캔들이 작아지고 개수가 많아지면 좋은 신호
- 반대로 **강하고 큰 캔들이 나오면 다이아고날이 아니다** (1-2, 1-2 확장형 의심)
- **4파가 완료돼야 다이아고날임을 확신할 수 있다.** 그전엔 확신 금지
- 큰 등급에서는 드물다 — **15분봉 이하 작은 등급에서 주로 발생**
- **엔딩 다이아고날 뒤에는 대부분 강한 반전이 따른다**
- **다이아고날은 연쇄한다** — 한 번 나오면 후속 조정도 쐐기형인 경우가 많다
- **확장값 0.786이 나오는 파동은 수렴형 다이아고날밖에 없다**
- **확산형에서 추세선을 뚫는 오버슛 = 더 깊은 하락 신호**
- **4파의 b는 반대편 추세선을 거짓돌파해도 된다.** 추세선 이탈로 카운팅을 폐기하지 마라

## 4.2 다이아고날 3대 판별 조건 ★실행 스크리너

SEALCRYPTO 강의의 핵심. **4파 끝에서 사서 5파를 길게 먹는다.**

| | 조건 | 판정 |
|---|---|---|
| **①** | 2파가 1파를 **61.8~78.6%** 되돌림 | 78.6%이 정배, 61.8%은 얕지만 충족 |
| **②** | 3파가 **1파 되돌림 61.8%** 수준 **또는** **0-1-2 확장 161.8%** | 둘 중 하나만 충족해도 성립 |
| **③** | 3→4 조정이 **irregular failure** 또는 **시간 소요 flat** | 어느 쪽이든 시간이 오래 걸린다 |

**→ 세 조건이 모이면 4파 종료 지점이 매수 자리, 5파를 장기 보유**

**보조 신호**
- **3파가 상대적으로 짧으면 5파가 크게 나온다는 신호**
- 시간은 예측이 어렵다 → **가격 기준으로 진입하고 묵혀라**

## 4.3 터미널 임펄스 감별법 (닐리)

- 1파·3파는 **깔끔한 임펄스**
- **5파가 abc처럼 끊긴다** ← 결정적 단서
- 2파와 4파가 겹친다
→ 이 조건이면 다이아고날로 작도

## 4.4 하락 리딩 다이아고날 트레이딩 셋업

물개방 자료. 숏 진입 셋업으로 완전히 구체적이다.

**판별 4단계**
1. 추세선 안에서 **5번 핑퐁**
2. **상단 추세선 이탈**
3. 이탈 지점이 시작부 되돌림 **0.382~0.5 구간**
4. 아래로 급락

**형태** — 상단 추세선은 가파르고 하단은 완만
**거래량** — 리딩은 튀어도 무방 / **엔딩이면 반드시 감소해야 한다**
(수렴형=입구 좁아짐=거래량 감소 / 확산형=입구 넓어짐=거래량 증가)

**매매**
- 진입: **0.382 / 0.5 분할 숏**
- 손절: **리딩의 맨 시작점** (실무상 0.786 자리)
- **리딩은 보통 0.786 되돌림 이상 안 넘긴다**
- 목표: 추세선 범위 크기의 **1.5배 하락이 정석**
- 1차 익절: **역피보 -0.618(=확장 1.618)과 확장피보 1.0의 중첩 자리**
- 연장파 안의 A리딩이면 되돌림이 더 얕다 (**0.236~0.382**)
- **리딩은 받지 마라** — 제대로 꽂으면 1.618/2.618 넘어 4.618까지 간다

# 5장 · 하모닉 패턴 (XABCD)

## 5.1 앵커링 — 이 레이어의 성패

> **"X 지점은 중요한 변곡점이라 생각되는 곳을 찾아야 한다."** (킹능사 강의)
> **"로그를 켜면 이전 변곡점이 더 확실하게 보인다."**

5개 점을 아무 데나 잡고 비율만 맞추면 하모닉은 **어느 차트에서든 발견된다.**
노이즈에서 억지로 뽑은 패턴은 근거가 아니라 소음이다.

**강제 조건 — 하나라도 어기면 후보를 만들지 않는다**

| | 조건 | 이유 |
|---|---|---|
| ① | **확정 피벗만** (D만 진행 중 허용) | 미확정 전환점은 전환점이 아니다 |
| ② | H/L **엄격 교대** | 같은 종류가 붙으면 방향 전환이 아니다 |
| ③ | 각 다리 ≥ **ATR × 1.8** | 노이즈 크기의 다리는 다리가 아니다 |
| ④ | 각 다리 ≥ **XA × 12%** | 한 다리가 미세하면 5점 구조가 아니다 |
| ⑤ | 각 다리 ≥ **3봉** | 몇 봉 만에 5점이면 진동이다 |
| ⑥ | C는 A를 초과하지 않는다 | 샤크만 예외 |

**이 필터를 통과한 뒤에야 비율을 본다. 순서를 바꾸면 안 된다.**

## 5.2 패턴별 비율

공통 C점: **AB의 0.382~0.886** (A 초과 전까지 인정)
공통 청산: **TP1 = 0.382 AD, TP2 = 0.618 AD**

| 패턴 | B (XA 되돌림) | D (PRZ) | BC 확장 | AB=CD | 손절 |
|---|---|---|---|---|---|
| **가틀리** | 0.618 | 0.786 | 1.13/1.272/1.414/1.618 | 1.0/1.27 | 1.0 XA |
| **딥 가틀리** | 0.618 | 0.786~0.886 | 1.618/2.0/2.24/2.618 | 1.0 | 1.0~1.13 XA |
| **뱃** | 0.382~0.5 | 0.886 | 1.618~2.618 | 1.0/1.27/1.618 | 1.13 XA |
| **얼터너트 뱃** | ≤0.382 | 1.13 | 2.0/2.24/2.618/3.14/3.618 | 1.618 | 1.27 XA |
| **나비** | 0.756~0.816 | 1.272 | 1.618/2.0/2.24 | 1.0/1.27 | 1.414 XA |
| **크랩** | 0.382~0.618 | 1.618 | 2.618/3.14/3.618 | 1.27/1.618 | 2.0 XA |
| **딥 크랩** | 0.886 | 1.618 (특수 1.902) | 2.0~3.618 | 1.0/1.27/1.618 | 2.0 XA |
| **영철(707)** | 0.677~0.737 | 1.414 | 2.0~3.618 | 1.0/1.27/1.618 | 1.618 XA |

**샤크** — 구조가 다르다. C가 A를 **초과**하고 D를 XA가 아니라 **XC**로 잰다.
B = 0.382~0.618 XA / C = 1.13~1.618 AB / **D = 0.886~1.13 XC** / BC = 1.618/2.0/2.24
TP1 = 0.5 CD, TP2 = 0.886 CD / SL = 1.13~1.27 XC
⚠ 라벨링 유파 차이는 §9 확인사항

**5-0 패턴** — 샤크 완성 후 BC의 0.5에 D를 추가. 목표 C점, 손절 0.618 BC, 추세추종

## 5.3 신뢰도 규칙

- **B값에 따라 패턴이 거의 결정된다** → B 가중치를 가장 높게
- AB=CD는 **신뢰도 보조값**
- **BC 1.13~1.618 마딧가가 XA 0.786과 중첩되지 않으면 신뢰도가 떨어진다**
  → **PRZ 폭이 좁을수록 고신뢰, 넓을수록 저신뢰**
- **PRZ 전체가 테스트된 뒤 즉시 되돌려야 유효.** 관통하면 패턴 실패
- 딥 크랩은 **BC 확장이 2.618을 넘길수록 신뢰도 상승**
- 샤크는 **X와 B에서 다이버전스가 자주 동반된다**

# 6장 · 근거 중첩 (Confluence)

자료 전체가 반복 강조하는 원칙:

> **서로 다른 방법이 같은 가격대를 가리킬 때만 그 자리를 신뢰한다. 3중첩이면 신뢰 타점.**

**중첩 대상 레벨**
- 닐리 **국면 종료 레벨** / 패턴 경계(:L5/:L3) ← **베이스, 최고 가중치**
- 파동 무효화 레벨 / 투영 목표
- 하모닉 PRZ / 손절
- 차트패턴 성립선 / 목표
- 회귀채널 상·중·하단, 피벗 추세선
- 주요 이동평균, 볼린저
- 최근 스윙 고저

**규칙**
- ATR의 **0.5배 이내**로 모이면 같은 자리
- **같은 출처끼리는 하나로 친다** — 한 근거가 여러 레벨을 낸다고 중첩이 아니다
- **3중첩 이상이 실행 타점 후보**, 2중첩은 참고용

**자료에서 확인된 구체적 중첩 조합**
- 역피보 -0.618 × 확장피보 1.0 (리딩 다이아고날 1차 익절)
- 되돌림 0.5 × 확장 1:1
- 피보 확장 0.618 × 1.618
- 하모닉: XA 0.786 × BC 1.13~1.618 × AB=CD

# 7장 · 보조 지표

## 7.1 RSI

- **RSI가 캔들보다 먼저 움직인다** (백분율 기준이라 민감)
- 75 이상 과매수 / 25 이하 과매도, 0·100에 가까울수록 반전 임박
- **RSI에도 추세선·차트패턴을 적용할 수 있다** — RSI 하락추세선 돌파 시 상승 전환
- **다이버전스가 가장 강력한 신호**
  - 상승: 가격 저점↓ + RSI 저점↑
  - 하락: 가격 고점↑ + RSI 고점↓
  - 이중 다이버전스도 가능하니 주의
- Failure swing은 가격 전환의 강한 신호

## 7.2 채널

| 종류 | 용도 |
|---|---|
| 패러렐 | 조정의 끝 찾기 |
| 베이스 | 기준 채널 |
| 가속 / 감속 | 추세 변화 |

- **조정의 끝은 3번 이상의 핑퐁 후 채널 중간점에서 이루어진다**
- 베이스 채널 하단 이탈 시 → 확장채널(복붙)을 그리면
  **찐반이 확장채널 중앙 또는 3/4 지점에서** 나온다
- 봉프레임은 **최소 1시간 이상** (2h·4h 권장)

## 7.3 이동평균

- 알트코인은 **200일 지수이동평균이 매우 중요**
- **역배열 종목 중 60선(EMA)에 닿는 것을 노린다** — 60선 이탈 시 재하락
- **일봉 기준**으로 판단할 것
- 200선을 아예 뚫어버린 종목은 제외

| 37 | **조정의 끝** | 채널 중간을 **3회 이상** 오간 뒤 **채널 중간점**에서 조정이 끝난다 |

> **피보나치 수열 매물대는 비트 가격대에 한정된 관찰이다.** 원문 근거도 비트 사례뿐이라
> (69k = 46368~75025의 0.786, 64k = 처음 닿는 0.618) 다른 종목에는 적용하지 않는다.
> `fibSequenceLevels` 가 심볼을 검사해 BTC 외에는 `null` 을 낸다.

> **VIP방 실시간 대화(ChatExport (5), 1.6MB)는 넣지 않았다.**
> 그쪽은 "어느 자리에 피보를 찍어 타점을 뽑는가"의 **사례 모음**이라
> 규칙이 아니라 판단의 기록이다. 규칙으로 굳히려면 따로 분석해야 한다.

## 핵심 규칙 3가지

**[T2] 역피보 반등 판정** — 직전 추세 구간(A) 대비 반등의 되돌림
| 반등 | 판정 | 기대 |
|---|---|---|
| ~38.2% (±4%p) | 조정 **미완**. 이 구간 전체가 더 큰 조정의 A(W) 하나 | 추가 진행 · 복합조정 의심 |
| ~61.8% (±4%p) | 조정 **종결**. ABC 완성 가능성 | 추세 재개 |
| 38.2 미달 | 추세가 매우 강함 | 종결 근거 없음 |
| 61.8 초과 | 추세 자체가 바뀌었을 수 있음 | A로 본 전제를 다시 확인 |

**[T3] 엘리엇 앵커 채널** — 선형회귀 채널과 달리 **파동 점에 직접 건다**
- 베이스 채널(0-1-2): 4파는 ① 하단 ② 중앙 ③ 미접촉(3파가 길 때) 중 하나
- 2-3-4 채널: 5파는 **채널 상단** 또는 **채널 중앙**에서 마감
- **5파 절단 시**: `(채널 중앙 + 채널 하단) / 2` ← 3파가 과도하게 길 때

**[T5] 거래량 사이클** — 신고점/신저점 갱신 + 거래량 감소 = **가짜 갱신**.
가짜 갱신이 **2회 연속**이면 반대 포지션 진입 근거.

## 중재 — "어느 쪽이 더 맞나"를 숫자로

기법마다 과거 구간에 그대로 적용해 적중 이력을 센다. 다만 **적중률만 보면 안 된다.**

> 초기 구현에서 닐리 국면 판정이 **84% 적중**으로 나왔다. 뜯어보니 32개 창이
> 전부 비방향성으로 분류됐고, 검증식이 분류식과 **같은 61.8% 조건을 다시 묻고**
> 있었다. 자기상관이지 예측력이 아니었다.

그래서 모든 백테스트가 **기저율**을 함께 낸다.

```
초과(edge) = 적중률 − 기저율
```

- 초과가 0 근처 → 이 차트에서 **아무 정보도 더하지 못했다**
- 초과가 음수 → **오히려 해로웠다**
- 표본 < 5건 → 우열 판단에 **쓰지 않는다**

기저율 산정도 공정해야 한다. 앵커 채널은 세 목표에 ±15% 창을 두면 채널 폭의
약 70%가 이미 덮이므로 기저율이 0.70이다. 또 이 기법은 "임펄스일 때"를 전제하므로
백테스트도 **절대 규칙 3개를 통과한 창에만** 적용한다 — 아무 6개 피벗에나 갖다 대고
안 맞는다고 하면 기법을 부당하게 깎는 것이다.

**중재는 승자를 정하지 않는다.** "이 구간에서 더 맞았다"까지만 말한다.
텔레그램 강의자들 본인도 그렇게 말한다 — *"알트별로 임펄스가 잘 맞는 분봉들이 따로 있다"*.

# 9장 · ⚠ 자료 간 충돌 — 확인 필요

정독 중 발견한 **서로 어긋나는 대목**이다. 임의로 하나를 고르지 않고 남겨둔다.

### ① 지그재그 B파 상한 — 세 값이 다르다 → **✅ 결정: 등급제**
- 총정리 [규칙]: **100%** / 총정리 [되돌림 조건]: **0.786** / 물개 2편: **0.618**
- **채택**: 셋 다 살리고 등급으로 구분 (`corrective.js` `ZIGZAG_B_TIERS`)

| B파 되돌림 | 등급 | 점수 |
|---|---|---|
| ≤ 61.8% | 전형적 | +10 |
| ≤ 78.6% | 정상 | 0 |
| ≤ 100% | 약함 (플랫 의심 병기) | −20 |
| > 100% | 지그재그 아님 | 폐기 |

### ② 확산삼각형 되돌림 상한 — 같은 문서 안에서 충돌
- 총정리 [규칙]: 이전 파동의 100% 이상 되돌리되 **105%를 넘지 않는다**
- 총정리 [비율]: C는 A의, D는 B의, E는 C의 **1.618** 되돌림

### ③ 삼각형 세부 구조 표기 오류로 보임
- 표제: `<Triangle> ( 3-3-3-3-3 )`
- 본문 규칙: "Triangle은 5개의 조정파동으로 구성된다. **( 5-5-5-5-5 )**"
→ 3-3-3-3-3이 맞고 본문이 오타로 보이는데, 확인 필요

### ④ 수렴형 다이아고날 5파와 추세선
- Elliott Basics(영문): 5파가 쐐기선을 **넘어선다** (Throw-Over)
- 총정리: 엔딩 다이아고날은 5파가 추세선에 **닿지 않을 수도** 있다 (절단)
→ 둘 다 가능한 것으로 보이나, 코드에서 어느 쪽을 기본으로 볼지

### ⑤ 다이아고날 4파 겹침이 필수인가 → **✅ 결정: 필수 유지**
- Elliott Basics: 4파는 1파 영역에 **반드시** 들어가야 한다
- 총정리: "반드시 겹쳐야 한다" + "안 겹쳐도 성립은 하지만 잘 안 나오니 신경 X"
- **채택**: 겹침을 필수로 본다. 오탐이 적고, 닐리의 터미널 임펄스 정의
  (2파·4파 겹침)와도 일치한다 (`elliott.js` `detectDiagonal`)

### ⑥ 샤크 패턴 라벨링 유파 차이
- 할모닉 최종: B=XA되돌림, C=AB확장, **D=0.886~1.13 XC**
- 2022 할모닉 for DK: A=XA되돌림, B=AB확장, **D=0.886~1.13 OB**
→ 0-X-A-B-C 라벨을 쓰는 유파와 X-A-B-C-D 유파의 차이.
  현재 내 코드는 **X-A-B-C-D로 통일**하고 XC 기준을 썼다

### ⑦ 나비 B점
- 할모닉 최종: **0.786** (0.886 닿기 전까지 유효)
- 2022 할모닉 for DK: **0.756~0.816**
→ 실질 동일. 현재 코드는 0.756~0.816 범위 사용

### ⑧ 복합조정에 지그재그가 두 번 올 수 있는가 → **✅ 결정: 올 수 있다**
- 통합본 3.5: "지그재그와 삼각형은 W/Y/Z 중 **최대 한 번씩만**"
- 닐리 표 A: `5-3-5 · x · 5-3-5` = **이중 지그재그** — 명시적으로 존재
→ 닐리가 베이스이므로 표 A 를 따른다. 두 자료는 사실 충돌이 아니라 명칭 문제로 읽힌다 —
  "조합(combination)"에 지그재그가 두 번 오지 않을 뿐, 그 경우는 **이중 지그재그**라는
  별도 패턴명을 갖는다. 코드는 W·Y가 모두 지그재그면 `doubleZigzag`, 서로 다르면
  `doubleCombo` 로 이름을 갈라 양쪽을 다 만족시킨다

### ⑨ 삼각형이 x파동 자리에 올 수 있는가 → **✅ 결정: 올 수 없다 (마지막 파동만)**
- 닐리 표 B: x파동으로 가능한 패턴에 `3-3-3-3-3 삼각형(수렴형 무제한만)` 이 들어 있다
- 닐리 표 A + 통합본 3.5: 삼각형은 **모든 행에서 마지막 자리에만** 나타난다
→ 표 A 가 실제 조합을 나열한 표이므로 그쪽을 따른다. `classifySegment` 는 마지막
  구간에만 `allowTriangle` 을 준다. 표 B 를 반영하려면 여기만 풀면 된다

### ⑩ x파동 상한 1.618 → **✅ 결정: 상한이 아니다**
- 통합본 3.5: "복합조정은 **1.618만 안 넘으면** 어떤 모양이든 성립"
- 닐리 조건 2: 두 번째 조정파동이 첫 번째를 **161.8% 이상** 되돌리면 그것이 x파동
→ 닐리 쪽은 1.618 초과를 **금지가 아니라 범주 2의 정의**로 쓴다. 상한으로 읽으면
  범주 2(세력 -3, 강세조정 +3)가 통째로 사라지므로 닐리를 따른다.
  다만 0.618~1.618 사이는 닐리도 정의하지 않았다 — 코드는 `범주 미확정`으로 두고
  세력 +2 와 -3 을 **둘 다** 표시한다 (경계에서 하나만 고르지 않는다는 원칙)

# 10장 · 지켜야 할 원칙

- **코드가 세고, LLM은 해석한다.** 계산은 전부 코드가 끝낸 뒤 문장으로 넘긴다
- **경계값에서는 후보를 남긴다** (중립성의 법칙)
- **복원하지 못한 규칙은 "추정"이라고 표시한다.** 법칙 6·7과 4·6·7 기호집합은
  원서 정독으로 확정되어 플래그가 해제됐다. 새로 추정하는 값이 생기면 다시 표시하라
- **닐리 수치의 단일 출처는 `neely-patterns.js`다.** 값마다 원서 쪽수가 붙어 있으니
  다른 모듈에 같은 상수를 복붙하지 말고 여기서 가져다 써라
- **자료 간 충돌은 임의로 정하지 않는다** — 9장에 남기고 확인받는다
- **모든 판정에 무효화 레벨을 붙인다.** 규칙이 깨지는 가격이 곧 손절선
- **근거가 적은 후보는 점수를 깎는다** (완성도 가중치)
- **불균형하고 특이한 패턴이 나오면 매매하지 않는다** — 모르는 자리에서는 쉰다
