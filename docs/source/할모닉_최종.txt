----- p.2 -----
Gartley Pattern 
 
B point : 0.618XA (0.786 닿기 전까지 유효) 
C point : 0.382 - 0.886AB. A 초과 전까지 인정 
 
PRZ 
- D point : 0.786XA (0.886 닿기 전까지 유효, 다만 예외 有 = Deep Gartley Pattern) 
- BC projection : 1.13 / 1.272 / 1.414 / 1.618 BC 
- AB = CD type : 1 / 1.27 AB = CD 
 
TP & SL 
TP1 : 0.382 AD, TP2 : 0.618 AD, SL : 1.0 XA 
 
Notes 
- 전체 PRZ test. 특히 0.786XA와 AB = CD를 기다려야 함. 
- 전체 PRZ 테스트가 이루어지는 즉시 되돌려야 함. 
 
예외 : Deep Gartley Pattern 
1.0 AB = CD가 0.786을 초과할 경우.
