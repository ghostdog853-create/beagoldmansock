Gartley Pattern 
 
B point : 0.588 - 0.648XA 
C point : 0.382 - 0.99AB. A 초과 전까지 인정 
 
PRZ 
- D point : 0.786XA (0.886 닿기 전까지 유효, 다만 예외 有 = Deep Gartley Pattern) 
- BC projection : 1.13 / 1.272 / 1.414 / 1.618 BC 
- AB = CD type : 1.0 / 1.27 AB = CD (AB = CD가 786을 넘길 경우에는 AB=CD테스트를 가급적 기다리세요.) 
 
TP & SL 
TP1 : 0.382 AD, TP2 : 0.618 AD, SL : 1.0 XA 
 
Notes 
- 전체 PRZ test. 특히 0.786XA와 AB = CD를 기다려야 함. 
- AB 1.272 (대틀리)를 응용하여 매매할 수 있다. 
 
예외 : Deep Gartley Pattern 
1.0 AB = CD가 0.786을 초과할 경우.

----- p.11 -----
RSI 원서 
저작권 이슈로 인해 캡처 삭제 후 내용 요약만 합니다. 
1) top and bottom 
    과매수나 과매도는 반전이나 반전이 임박함을 뜻함 
2) chart formations 
    Rsi에도 차트패턴을 적용시킬 수 있음 
3) faliure swings 
    Failure swing은 가격 전환의 강한 신호이다. 
4) 지지 저항 
    추세선을 통한 지지저항, rsi 수치에 의한 지지저항이 나타날 수 있다. 
5) 다이버전스 
    다이버전스는 터닝포인트를 나타내는 강력한 신호이다. 
 
BAMM (뱀) 
 
Failure Swing 개념을 적용한 매매법이다. B가격을 돌파할 때 진입하여 D에서 청산하거나 스위칭. 
 
XB 추세선을 기준으로 진입하는 방법도 있다. 원서에는 없는 드래곤 패턴의 원리

----- p.12 -----
RSI BAMM (방울 뱀) 
 
다이버전스와 피보나치를 이용한 진입 방법이다. 
 
조건 1) 다이버전스를 형성해야 한다. 
 
조건 2) RSI가 중간에 50을 넘기고 와야한다. 
 
하모닉패턴과의 연계도 가능하다. 
 
RSI BAMM (방울 뱀) 매매 방법 
 
방법 1) 피보나치를 그어두고 반등 지점을 예측하여 들어간다. 
 
방법 2) RSI가 과매도 과매수를 벗어난 채로 마감하면 들어간다. 
 
Tip : 샤크 or 싸이퍼 패턴과의 연계도 가능하다. 샤크와의 연계를 노린다면 1.618 ab에선 꼭 익절을 하자.

----- p.13 -----
마지막으로 드리는 Tip 
 
- 하모닉 패턴은 D점을 예측하는 용도로 쓰는 것이 아닙니다. D점 진입이 원칙입니다. 
 
- 모든 시간봉에서 쓸 수 있습니다.  
 
- 로그 차트에서 쓰는 것은 곤란합니다. 
 
- 추세의 끝에서 종종 등장합니다. 괜찮은 지점을 잡았다면 홀딩을 계속 해보는 것도 나쁘지 않습니다. 
 
- 일봉, 주봉에서 알트 저점 잡을 때도 유용합니다 
 
- 0.382 반익절은 꼭 하십시오. 
 
- BC와 AB=CD는 바뀌질 않습니다. X점을 정하기 애매할 때 BC와 AB=CD를 응용하여 X점을 정해보세요. 
 
- 맨 처음에 올려드린 사진의 Perfect 패턴의 비율을 기준으로 X점을 설정할 수 있습니다. 
 
- 단독으로 쓰기 보다는 추세선, 다이버전스, 엘리엇 파동 등의 근거를 함께 사용해야 합니다. 
 
- 횡보장, 특히 하락 횡보장에서 강합니다. 
 
- 거래량이 터지고 횡보할 때 단타로 쓰기 좋습니다. 
 
- 되도록이면 추세 방향대로만 쓰기를 권장합니다. 
 
- 5-0 패턴은 큰 타임테이블에서 다른 근거가 있을 때 꼭 쓰십시오. 체감상 승률이 높지 않습니다. 
 
- 영철 패턴은 테스트 중이니 거르실 거면 거르십쇼. 쓰다 돈 잃어도 책임 안 집니다. 
 
- (불리쉬 패턴 기준) C지점 찍음 -> B가격 하향 돌파 -> D 못찍고 반등 -> C 가격 상향 돌파 
  이 경우 그려뒀던 하모닉은 폐기입니다. 
 
- 하모닉 원서는 홈페이지에서 무료로 다운받을 수 있습니다. 구글링 ㄱㄱ 
 
- 원서는 3권만 발췌독 해도 충분하다고 생각합니다. (bamm 이론은 2권) 
 
- 차트 갤러리에 ‘모닉’ 들어간 글들은 거의 모두 봅니다. 질문글은 제목에 ‘모닉’ 넣어서! 
 
- HPC 사지 마세요. 돈값 못하는 거 같습니다. 카니형 사랑하거나 돈 많으면 ㄱㄱ. 카니형 미안해! 
 
- 하모닉을 이용하여 자신만의 매매법과 적정배율 및 리스크관리 원칙을 세우세요.
